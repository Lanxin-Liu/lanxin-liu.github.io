How the annotation works

  1. Find the grasp

    Align recorded gripper closure and release with the camera capture times. Prepare an event window for each grasp.

  2. Propose nearby objects

    Estimate the contact region from the visible robot and prompt SAM 2 with image points. Search a magnified crop if the first pass finds no candidate that passes validation.

  3. Check the motion

    Compare candidate motion with the gripper and reject stationary background and moving shadows. Check that the target and robot are separate before contact or after release.

  4. Track and export

    Propagate the chosen mask forward and backward through the event window. Record missing masks and flag abrupt changes in area or position.
